# Git Workflow

## Branches
- `main` – stable, production-ready code (tagged releases)
- `dev` – integration branch for completed features
- `feature/*` – one branch per feature or task

## Flow
feature/* → PR → dev → PR → main (tag a release)

## Commit message convention
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `chore:` maintenance
